Prerequisites

Python 3.12+ required. Check your version:
python --version

Setup Steps

1. Install dependencies (using Poetry):
cd "D:\Media\Movies\keerthi purswani\agentic-ai-system-design-course\AgenticAISystemDesign-main\AgenticAISystemDesign-main\capstone_project"
poetry install

Or with pip:
pip install -e .

2. Create .env file in the project root with your API keys:
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key  # if using Claude models

3. Optional - Set up Redis (for semantic caching, enabled by default):
- Install Redis or use Docker: docker run -d -p 6379:6379 redis
- Or disable in config.yaml: set enabled: false under semantic_cache

Run RUMI

Using Poetry:
poetry run educosys_claude

Or directly:
python -m educosys_claude.main

Available Commands

Once running, try these:
- /ask <question> — Ask about your codebase
- /plan <goal> — Create and execute a task plan
- /reindex — Re-index current directory
- /new_session — Start a fresh conversation
- /task_status — Show task progress
- /exit — Quit
