# RUMI---An-agentic-RAG-system-for-codebases
A Claude-powered code assistant

Next steps to run RUMI:
1. Clone from GitHub:
git clone https://github.com/leninathikam/RUMI---An-agentic-RAG-system-for-codebases.git
cd RUMI---An-agentic-RAG-system-for-codebases
2. Install dependencies:
pip install -e .
3. Create .env with API keys:
OPENAI_API_KEY=your_key
ANTHROPIC_API_KEY=your_key
4. Run RUMI:
python -m rumi_claude.main
